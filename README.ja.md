# LogoScan

**AviUtl のロゴ解析を、AviUtl なしで。**

録画ファイルから、透過性ロゴフィルタで使う `.lgd` を作る。

<sub>架空のロゴを重ねたテスト映像で、位置を検出して解析したところです。右下が取り出したロゴの不透明度で、黄色い枠の中はロゴを消した絵を表示しています。</sub>

AviUtl のロゴ解析プラグイン（logoscan）と同じ形式の `.lgd` を作ります。
作った `.lgd` は透過性ロゴフィルタ（delogo）でそのまま読めます。
画面（`lgdscan-gui`）とコマンド（`lgdscan`）の 2 つがあり、中身は同じです。

映像は ffmpeg / ffprobe コマンドで読みます。

## ダウンロード

[Releases](https://github.com/DeepRegular/LogoScan/releases) から取ってください。

- **Windows**: `LogoScan-<版>-windows-x86_64.zip` を好きな場所に展開して、`lgdscan-gui.exe` を起動します。
  FFmpeg は `ffmpeg` フォルダーに同梱しています。
- **Linux**: `LogoScan-<版>-linux-x86_64.tar.gz` です。Ubuntu 22.04 以降など、glibc 2.35 以上で動きます。
  FFmpeg はディストリビューションのものを入れてください（`sudo apt install ffmpeg`）。

ffmpeg と ffprobe は、プログラムと同じフォルダー、その中の `ffmpeg` フォルダー、PATH の順に探します。

## 画面（lgdscan-gui）

```
lgdscan-gui 録画.ts [ロゴ.lgd]
```

録画ファイルはウィンドウに落としても開けます（Shift を押しながら落とすと追加になります）。

1. **ロゴの位置を検出** を押すと、録画全体から 120 枚のキーフレームを取り出して、ロゴらしい場所に枠を合わせます。
   候補が複数あれば一覧から選べます。「縁の出る割合」と「余白」を動かすと、その場で候補を出し直します。
2. 枠は絵の上で直せます。
   - 枠の外でドラッグすると新しく囲み、中でドラッグすると動かし、辺や角をつまむと伸び縮みします。
   - 矢印キーで 1 画素ずつ動かし、Shift+矢印で幅と高さを変えます。
   - ホイールで拡大・縮小、右ボタンか中ボタンのドラッグで表示を動かし、右ダブルクリックか「全体表示」で元に戻します。
     2 倍を超えると画素がそのまま見えます。
3. **解析開始** を押します。終わると、透明度を白黒にした画像が出て、絵はロゴを消した状態に切り替わります。
   下のスライダーで別の場面に動かして、消え方を確かめられます。
4. ロゴ名を入れて **保存…** を押します。

動くロゴは、「解析」の欄で **動くロゴ** に切り替えます（下の「動くロゴ」の節も見てください）。
録画を何本も開き（「追加…」か、Shift を押しながら落とす）、アニメーションが通る範囲を枠で囲んで **解析開始** を押します。
終わると、結果の欄のスライダーでアニメーションの 1 フレームずつを見られます。
録画ごとの開始フレームの一覧から 1 本選ぶと、その録画の同じフレームを、ロゴを消した状態で表示します。
**保存（.ldp）…** で全フレームを、**止まったロゴを保存（.lgd）…** で止まったあとのロゴを書きます。
.ldp を開くと、中のフレームを見られます。

## コマンド

```
lgdscan scan 録画.ts --rect 1700,34,157,45 -o ロゴ.lgd -n MyLogo
```

`--rect` は X,Y,幅,高さ です。ロゴを少し余白をつけて囲んでください。
矩形のいちばん外側の 1 画素の枠を背景として読むので、枠にロゴがかからないようにします。
入力は何本並べてもかまいません。本数が多いほど、背景の色に幅が出て結果が安定します。

| オプション | 既定 | 内容 |
|---|---|---|
| `--start` / `--end` | 全体 | 読む範囲（秒） |
| `--step N` | 1 | N フレームに 1 枚だけ読む |
| `--threshold T` | 12 | 枠の画素が背景のモデルからどれだけ外れてよいか（8 ビットの階調） |
| `--background plane\|flat` | plane | plane は枠に勾配を当てはめ、flat は枠の平均 1 色（logoscan と同じ） |
| `--scan auto\|progressive\|interlaced` | auto | 4:2:0 の色差を縦にどう補間するか |
| `--max-frames N` | 8000 | 当てはめに使うフレームの上限。超えた分は無作為に間引く |
| `--passes N` | 3 | 最小二乗の回数。2 回目からは外れ値を除く |

ロゴの位置を探すだけなら:

```
lgdscan detect 録画.ts
```

候補を `--rect X,Y,W,H` の形で、確からしい順に出力します。`--share`（縁の出る割合、既定 0.45）、`--margin`（余白、既定 3）、`--samples`（キーフレームの枚数、既定 120）を変えられます。

そのほかのコマンド:

- `lgdscan info ロゴ.lgd` … ヘッダの中身を表示します
- `lgdscan compare A.lgd B.lgd` … 2 つのロゴを画素ごとに比べます
- `lgdscan render ロゴ.lgd 出力.pgm` … 輝度の不透明度を白黒の画像にします
- `lgdscan erase ロゴ.lgd 録画.ts 秒 出力.ppm` … その時刻の絵で、消す前と消した後を左右に並べます

## 仕組み

ロゴは `観測値 = 背景 × (1 − α) + ロゴの色 × α` で重なっています。
背景がわかるフレームを集めて、画素ごと・Y/Cb/Cr ごとに `観測値 = A × 背景 + B` を最小二乗で当てはめ、
`dp = (1 − A) × 1000`、`色 = B / (1 − A)` を書き込みます。ここは logoscan と同じ式・同じ丸めです。

logoscan と違うところが 3 つあります。

- **背景の推定**: 枠が 1 色でなくても、なだらかな勾配なら使います。平坦な背景のフレームだけでは、白と黒の画面ばかりが集まります。
  白い画面ではロゴが見えず、黒い画面（場面転換）ではロゴが出ていないことが多く、どちらからも何もわかりません。
- **ロゴの出ていないフレームを除く**: 一度当てはめたあと、ロゴの濃い画素で「ロゴあり」と「ロゴなし」のどちらがよく説明できるかをフレームごとに比べます。
  ロゴなしのほうが合うフレームを外して当てはめ直します。CM や場面転換が混ざっても、範囲を選び直さずに済みます。
- **色差の補間**: AviUtl に入ったときと同じ形にしてから解析します。横は偶数画素に標本を置いて奇数画素は両隣の平均、
  縦はインターレースならフィールドごと（MPEG-2 の位置）に補間します。ここが合っていないと、色差の不透明度が参照と合いません。

## 動くロゴ

番組の頭で、ロゴがアニメーションしながら現れて、そのまま止まる局があります。
動きは毎回同じなので、アニメーションの 1 フレームごとにロゴを 1 つずつ作れば消せます。

```
lgdscan anim 録画1.ts 録画2.ts 録画3.ts … --rect 0,0,704,320 -o anim.ldp --still 止まったロゴ.lgd
```

使い方は次のとおりです。

1. 同じ局の録画を何本も用意します。1 本では解析できません。30 本ほどあると安定します（十数本では、最後のほうのフレームがうまく求められず、警告を出します）。
2. 録画はそれぞれ、ロゴのアニメーションが始まる少し前から、ロゴが画面から消えるまでを切り出します（10 秒ほど）。
3. ロゴが動き回る範囲を `--rect` で、全部入るように指定します（画面では枠で囲みます）。

- `--rect` はアニメーション全体が収まる範囲です。広くするとメモリを使います（704×320 で 72 本なら約 1.3GB、3 分ほど）。
- 書き出すファイルの形式は .lgd と同じで、フレームごとのロゴが `0`、`1`、`2`… という名前で順に入ります。
  矩形はフレームごとに、そのフレームのロゴに合わせて切り詰めます。最後の 1 枚は、ロゴが止まった最初のフレームです。
- `--still` を付けると、止まったあとのロゴを別の .lgd にも書きます。
- アニメーションが始まる位置は録画ごとに違っていてかまいません。`--search`（既定 90 フレーム）までのずれは自分で合わせ、
  録画ごとに何フレーム目から始まったかを表示します。
- 同じ入力なら、何度実行しても同じファイルになります。
- 不透明度は 999 で止めます。delogo は 1000 を超えた画素で絵を反転させてしまうためです。

書いた .ldp は、AviSynth の delogomod でそのまま使えます。
`EraseLogomod` は .ldp の中のロゴを上から順に 1 フレームずつ当て、使い切ったあとは最後の 1 枚を当て続けます。
参照の .ldp と同じく、動きが止まってからあとは `end` と `fadeout` で指定する前提です。
`start` には、lgdscan が録画ごとに表示する開始フレームを入れます。
`end` と `fadeout` は、止まったロゴが消えていく様子を録画から測って表示し、サンプルスクリプト（下）の既定値にも入れます。

```
EraseLogomod(logofile="anim.ldp", start=3, end=3+232, fadeout=22)
```

測り方: 止まったあとのフレームごとに、止まったロゴを何割の濃さで消すと縁の段差がいちばん小さくなるかを求め、
録画全部の中央値の推移に、delogomod のフェードの形（`end` の手前 `fadeout` フレームで直線的に薄くなる）を当てはめます。
手元の 72 本では、濃さは 209 フレーム目まで 0.99 のままで、そこから下がって 234 フレーム目で 0 になりました。
delogomod に付いている例（`end=start+218, fadeout=28`）では、この録画ではロゴがまだ濃いうちに消し始めてしまいます。
ロゴが消えるところまで録画に入っていないと、`end` と `fadeout` は測れません（そのときは警告を出します）。
開始フレームは、lgdscan が読んだ最初のフレームを 0 として数えています。AviSynth 側の読み込み方によっては先頭のフレーム数がずれるので、消え方を見て確かめてください。

### サンプルスクリプト

ロゴデータと一緒に、使い方のサンプルを同じ名前の .avs で書きます（CP932、改行は CRLF）。
`lgdscan anim` は .ldp と一緒に必ず書きます。画面では、保存のときに「サンプルの .avs も書く」が付いていれば書きます。
あとから作るなら `lgdscan avs ロゴ.ldp --end 232 --fadeout 22` か `lgdscan avs ロゴ.lgd` です。

.ldp には delogomod の `EraseLogomod` を包んだ関数を書きます（`end` と `fadeout` は測った値が既定値になります）。

```
function EraseMovingLogo(clip c, int "start", int "length", int "fadeout")
{
  start = default(start, 0)
  length = default(length, 232)
  fadeout = default(fadeout, 22)
  return c.EraseLogomod(logofile="anim.ldp", start=start, end=start+length, fadeout=fadeout)
}
#EraseMovingLogo(16)
```

.lgd には delogo の `EraseLOGO` を包んだ関数を書きます（`EraseStillLogo(start, end, fadein, fadeout)`、`end` を省くと最後まで）。
録画の読み込みや `LoadPlugin` は書きません。自分のスクリプトに取り込んで使ってください。

## ロゴの位置の検出

場面が変わってもロゴは動かないことを手がかりにします。
録画全体から間隔をあけてキーフレームを取り出し、画素ごとに「縁（輝度の段差）が出ているフレームの割合」を数えます。
ほとんどのフレームで縁が出ている画素を集め、文字どうしの隙間を埋めて 1 つのかたまりにまとめると、それが候補になります。
CM の間ロゴが消えていても、割合が下がるだけで見つかります。
画面の端に近い画素と、画面の半分を超える長さのかたまり（レターボックスの境目など）は外します。

## ロゴ名の文字コード

AviUtl と同じく CP932（Windows-31J）で書きます。
Linux や macOS で入力しやすい「〜（U+301C）」「‖」「—」「¢」「£」「¬」は、CP932 にある同じ見た目の文字（～ ∥ ― ￠ ￡ ￢）に置き換えます。
それでも書けない文字（é や絵文字など）が入っていると、保存する前に知らせます。
名前は 31 バイトまでです。超えた分は、文字の途中で切れないように落とします。ファイルはいつも ver0.1 で書きます。
読むときは CP932 として読みます（UTF-8 として正しいバイト列なら UTF-8 として読みます）。

## 精度

放送の録画 1 本（MPEG-2 1080i、30 分、半透明の白いロゴ）を全部読み、同じロゴを AviUtl で解析した `.lgd` と比べた結果です。

| | 不透明度の相関 | 平均の差（/1000） |
|---|---|---|
| Y | 0.9996 | 2.1 |
| Cb | 0.9944 | 5.9 |
| Cr | 0.9929 | 6.4 |

同じ番組の別の回で作ったものどうしの差も同じくらいです（色差の相関 0.994）。
これより細かい差は、どのフレームを使ったかで決まります。

## まだできないこと

- フェードイン・フェードアウトなど（fi/fo/st/ed）は 0 のままです。
- `scan` が 1 つのファイルに書くロゴは 1 つだけです。

## ビルド

```
cargo build --release
```
